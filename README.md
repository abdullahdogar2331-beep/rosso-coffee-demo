# Rosso Coffee Co. — Concept Website Demo

Independent, unofficial concept website. Not affiliated with or endorsed by Rosso Coffee Co.

## Website
- `index.html` contains the complete responsive HTML, CSS and vanilla JavaScript website.
- Menu content and photos are illustrative.
- Reservation form is a front-end demo only; it does not send or store booking details.
- Confirm the cafe's real address, menu, prices, opening hours and official social links before using this as a public business website.

## GitHub Pages
1. Open repository Settings → Pages.
2. If asked for a source, select **GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` deploys the site when code is pushed to `main`.
4. Once the workflow succeeds, the Pages URL should be `https://abdullahdogar2331-beep.github.io/rosso-coffee-demo/`.
